# Ahana Expert Homes

Ahana Expert Homes is a premium, high-converting real estate landing page designed to showcase luxury residential projects. Built with modern web technologies, it offers a seamless, immersive experience for potential homebuyers, featuring interactive floor plans, dynamic galleries, and a high-performance responsive design.

## ✨ Key Features

- **Immersive Hero Section:** Captivating first impression with premium visuals and clear call-to-actions.
- **Interactive Project Overview:** Detailed information about the project's vision, architecture, and lifestyle.
- **Amenities Showcase:** A visually rich grid highlighting the premium facilities (Gym, Pool, Clubhouse, etc.).
- **Dynamic Floor Plans:** Interactive layouts allowing users to explore different unit configurations.
- **Premium Gallery:** A smooth, responsive masonry-style gallery to showcase project interiors and exteriors.
- **Location Insights:** Integrated maps and key landmarks to highlight connectivity.
- **Enquiry System:** Strategic lead generation forms with validation.
- **Advanced Animations:** Smooth scroll transitions and micro-interactions powered by Framer Motion.

## 🚀 Tech Stack

- **Framework:** [React 18](https://reactjs.org/)
- **Build Tool:** [Vite 6](https://vitejs.dev/)
- **Styling:** [Tailwind CSS 4](https://tailwindcss.com/) (using the new Vite plugin)
- **Animations:** [Motion](https://motion.dev/) (formerly Framer Motion)
- **UI Components:** [Radix UI](https://www.radix-ui.com/) & [Lucide React](https://lucide.dev/)
- **State Management:** [React Hook Form](https://react-hook-form.com/) (for enquiries)
- **Routing:** [React Router 7](https://reactrouter.com/)

## 🛠️ Installation & Setup

Before you begin, ensure you have [Node.js](https://nodejs.org/) installed.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/KartikJoshi007/AHANA_EXPERT_HOMES.git
    cd AHANA_EXPERT_HOMES
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Start the development server:**
    ```bash
    npm run dev
    ```

4.  **Build for production:**
    ```bash
    npm run build
    ```
